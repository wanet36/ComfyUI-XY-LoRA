# comfyui_batch_text

批量读取 txt 提示词 → 一段预览文本，或逐条编码成条件（一条文本一张图）。

从 `comfyui_XYLoRA` 里拆出来的独立插件，只做文本，不依赖任何第三方节点。

## 安装

把 `comfyui_batch_text` 文件夹放进 `ComfyUI/custom_nodes/`，重启 ComfyUI，Ctrl+F5 刷新页面。两个节点在菜单分类 `Batch Text` 下。

## 两个节点

### 批量文本读取（仅输出文本） · `comfyui_BatchTextPrompts`

只读文件、只输出一段带编号的纯文本，用来检查提示词有没有读对。不参与生图。

| 输入 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `文本文件夹` | STRING | 空 | 存 txt 的目录；留空 = ComfyUI 的 `input/` |
| `文件匹配` | STRING | `*.txt` | glob 通配符 |
| `递归子目录` | BOOLEAN | 关 | 是否递归扫描子目录 |
| `切分方式` | 下拉 | 按空行分段 | `按空行分段` / `按行` / `整文件一条` |
| `排序` | 下拉 | 文件名升序 | 文件名 / 修改时间，各带升降序 |
| `编码` | 下拉 | utf-8-sig | `utf-8` / `utf-8-sig` / `gbk` |
| `最大条数` | INT | 32 | 1 ~ 512，达到上限即停止读取 |
| `标签内容` | 下拉 | 源文件名 | 标签用 `源文件名` / `提示词原文` / `序号` |

**输出**：`文本预览`（STRING，非列表）。格式：

```
共 3 条提示词
============================================================
[01] first
    1girl, solo, masterpiece

[02] first_02
    ...
```

### 批量文本生条件（一条文本一张图） · `comfyui_BatchTextToCond`

读 txt → 逐条 `clip.tokenize` + 编码，正向条件按**列表**输出，KSampler 因此会逐条执行。

在上一节点的基础上多了：

| 输入 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `clip` | CLIP | — | 必接 |
| `起始文件序号` | INT | 1 | 从第几个文件开始（1 = 第一个），用于断点续跑 |
| `额外正面提示词` | STRING | 空 | 多行；拼到每条正向提示词末尾（质量词、画风词） |
| `负面提示词` | STRING | 通用负面词 | 多行；整批共用同一个负面条件 |

其余输入同上，但 `切分方式` 默认是 `整文件一条`（一个文件一张图）。

**输出**

| 名称 | 类型 | 说明 |
|---|---|---|
| `正向条件` | CONDITIONING 列表 | 每条文本一个，逐条执行 |
| `负向条件` | CONDITIONING 列表 | 同一份负面条件复制 N 份 |
| `标签列表` | STRING 列表 | 接 `XY lora图像保存` / `XY lora图像标注` 用作命名、图上文字 |
| `文本预览` | STRING | 整段文本（非列表），接 ShowText 查看 |

**标签生成规则**（`标签内容`）

- `源文件名`：文件内第一条用文件名，同文件后续条目加 `_02`、`_03` 后缀；
- `提示词原文`：直接用提示词当标签（太长会把文件名拉长，注意清洗后最长 120 字符）；
- `序号`：`001`、`002`…

## 典型用法

```
[批量文本生条件] ─正向条件─► KSampler ─► VAEDecode ─► [XY lora图像保存]
        └─标签列表──────────────────────────────────┘
        └─文本预览─► ShowText（核对读到的提示词）
```

## 常见问题

**报错「没有读到任何提示词」**
检查三处：`文本文件夹` 是否存在、`文件匹配` 是否匹配到文件（如 `*.txt` vs `*.md`）、文件内容是否为空。若用了 `起始文件序号`，它超过文件总数时也会报这个错。

**中文乱码**
文件是 GBK 保存的就选 `gbk`；带 BOM 的 UTF-8 选 `utf-8-sig`（默认）。

**读到的条数比预期少**
`最大条数` 默认 32，超出的部分直接截断。

**改了切分方式，条数没变**
`按空行分段` 只认「空行」，单个换行会被当成同一段并压掉多余空白；需要一行一条就选 `按行`。
